# appseccharlie.com

Charlie's static personal site, built with Eleventy.

## Local development

```bash
npm ci
npm run build
npm run dev
```

Open <http://127.0.0.1:4173/>. Run `npm run build` before the Playwright browser tests with `npm test`.

## Deployment

GitHub Actions builds and tests the Eleventy site, then deploys the tested static assets to Cloudflare Workers using Wrangler on pushes to `main`. The Worker serves static assets only, with no application backend.

## Field Notes

Add a Markdown file to `src/field-notes/`. Its filename becomes the URL slug,
so `example-note.md` is published at `/field-notes/example-note/`.

```yaml
---
title: Note title
date: 2026-09-06
description: A short description of the note.
draft: true
---
```

Draft notes are available with `npm run dev`, but are excluded from production
collections and output generated by `npm run build`. Set `draft: false` when a
note is ready to publish. The Field Notes index is generated automatically in
reverse chronological order.
